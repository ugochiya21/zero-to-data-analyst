# Zero to Data Analyst: practice files

Free practice files for the book **Zero to Data Analyst: SQL, Excel, Power BI and Python, Step by Step, for Complete Beginners** by **DataBridge Academy**.

## Download the files for your edition

| Your book | Download |
|---|---|
| **International Edition (US$)**: Amazon paperback and Kindle | [Practice_Files_INTERNATIONAL_EDITION_USD.zip](Practice_Files_INTERNATIONAL_EDITION_USD.zip) |
| **Nigeria Edition (₦)** | [Practice_Files_NIGERIA_EDITION_Naira.zip](Practice_Files_NIGERIA_EDITION_Naira.zip) |

Click the file name, then click the **Download** button (↓) on the right.

## What's inside
- `brightmart.sql`: the BrightMart retail database (load it in Chapter 1)
- `marketing_campaigns.sql` / `.csv`: an extra table for import practice
- `data/*.csv`: every table as CSV, for Excel, Power BI and Python
- `data/sales_flat.csv`: completed sales, one row per item sold
- `data/supplier_orders_messy.csv`: a messy file for cleaning practice
- `data/bm_online_orders.json` and `data/exchange_rates_backup.json`: JSON and API practice (Chapter 28)

## Quick start
1. Unzip the file into a folder you'll remember, e.g. `Documents\DataAnalysis`.
2. Follow Chapter 1, Section 2 to install MySQL, then load `brightmart.sql`.
3. Check: `SELECT COUNT(*) FROM brightmart.orders;` should return **13232**.

All data is fictional and was generated for teaching. Free to use for personal learning and teaching.
